## 平台即服务（PaaS）

- [ampt.dev](https://getampt.com/) — 让团队免于复杂配置与基础设施管理，在 AWS 上构建、部署、扩展 JavaScript 应用。免费 Preview 方案：每小时 500 次调用、每天 2,500 次、每月 50,000 次；自定义域名仅限付费方案。
- [anvil.works](https://anvil.works) — 只用 Python 开发 Web 应用；免费档应用不限量、超时 30 秒。
- [Apply.build](https://apply.build/) — 免费构建与部署你的 GitHub App：0.5 vCPU / 512 MiB RAM、欧洲服务器、自动防火墙、实时性能指标；可运行 Node.js、Python、Go、Java、静态站点、微服务等。
- [appwrite](https://appwrite.io) — 项目数不限且不暂停项目（支持 websockets），含认证服务；免费档每项目 1 个数据库、3 个存储桶、5 个函数。
- [Clever Cloud](https://clever.cloud) — 欧洲 PaaS：自动部署、自动伸缩、托管数据库、基于 Git 的工作流；注册送 €20 免费额度，受限 DEV 方案含免费 MySQL 与 PostgreSQL，另有 Heptapod、FS Buckets 等服务的免费额度。
- [Choreo](https://wso2.com/choreo/) — 云上的 AI 原生内部开发者平台；免费档最多 5 个组件与每月 $100 额度。
- [codenameone.com](https://www.codenameone.com/) — 面向 Java/Kotlin 开发者的开源跨平台移动应用开发工具链；商业使用免费、项目数不限。
- [Cohesivity](https://cohesivity.ai) — 专为 AI Agent 打造的无头后端与服务：托管、数据库、存储、LLM 与第三方 API；可 Agent 化注册。免费档：10 个项目、10 万次边缘请求、10GB 对象存储、100 封邮件、AI 与搜索每月 $5 额度。
- [Daestro](https://daestro.com) — 跨云厂商与本地运行计算任务；免费档最多 10 个并发任务、2 个计算实例、自托管算力、1 个云厂商、1 个容器注册表、1 个 cron 任务。
- [Deno Deploy](https://deno.com/deploy) — 在全球边缘运行 JavaScript、TypeScript 与 WebAssembly 的分布式系统；免费档每天 10 万次请求、每月 100 GiB 数据传输。
- [domcloud.co](https://domcloud.co) — Linux 托管服务：GitHub CI/CD、SSH、MariaDB/Postgres 数据库；免费版 1GB 存储、每月 1GB 流量，且仅限免费域名。
- [encore.dev](https://encore.dev/) — 后端框架：静态分析自动提供基础设施、免样板代码等；爱好者项目含免费云托管。
- [faable.com](https://faable.com/) — 自动识别 Python 与 Node.js 框架并部署应用；免费档每项目 1 个 0.5 CPU / 1GB RAM 实例、10GB 带宽、每天 10 次成功部署、自动 SSL、内置 WAF，支持 OAuth 2.0 / OIDC 认证；无流量 2 小时后休眠；欧洲服务器。
- [flightcontrol.dev](https://flightcontrol.dev/) — 在你自己的 AWS 账户上用类 git push 工作流部署 Web 服务与数据库等；个人 GitHub 仓库、1 名开发者免费；AWS 费用由 AWS 直接结算，可用其额度和免费档。
- [gigalixir.com](https://gigalixir.com/) — Elixir/Phoenix 应用：1 个永不休眠的免费实例 + 免费档 PostgreSQL（限 2 连接、10,000 行、无备份）。
- [Northflank](https://northflank.com) — 用强大的 UI、API 与 CLI 构建部署微服务、任务与托管数据库；从容版本控制与外部 Docker 注册表无缝伸缩容器；免费档含 2 个服务、2 个 cron 任务、1 个数据库。
- [Ownkube](https://ownkube.io) — 在你自己的 AWS 账户内免费运行单节点 k3s，git push 即运行应用、数据库与 worker；高效使用你的 AWS 额度。
- [pipedream.com](https://pipedream.com) — 面向开发者的集成平台：以任意触发器开发任意工作流，工作流是[可免费运行](https://docs.pipedream.com/pricing/)的代码；无需管理服务器或云资源。
- [pythonanywhere.com](https://www.pythonanywhere.com/) — 云 Python 应用托管；入门账号免费：1 个 Python Web 应用（your-username.pythonanywhere.com 域名）、512MB 私有文件存储、1 个 MySQL 数据库。
- [Runsite](https://runsite.app/) — 欧洲 PaaS：GitHub 自动部署 Web 服务或静态站点（免费 1 web，0.1 vCPU/256MB）、托管 PostgreSQL 与 Valkey/Redis（免费 30 天）、事务邮件（每月 3,000 封免费）、S3 兼容存储（5GB 免费）——建站起步基本齐备；服务器在德国。
- [Val Town](https://www.val.town) — 协作式 TypeScript/JavaScript serverless 平台：脚本、HTTP 端点与 cron 任务。免费方案：公共 vals 不限量、cron 最短间隔 15 分钟、每次运行墙钟时间 1 分钟、日志保留 3 天；免费不支持自定义域名。
- [WunderGraph](https://cloud.wundergraph.com) — 开源平台，快速构建、交付与管理现代 API；内置 CI/CD、GitHub 集成、自动 HTTPS。[免费方案](https://wundergraph.com/pricing)最多 3 个项目、1GB 出站流量、每月 300 分钟构建时间。
- [YepCode](https://yepcode.io) — 在 serverless 环境连接 API 与服务的一体化平台：有 NoCode 工具的敏捷便利，同时保留编程语言的全部能力；免费档含 [1,000 yeps](https://yepcode.io/pricing/)。


## 后端即服务（BaaS）

- [Activepieces](https://www.activepieces.com) — 在应用后端构建连接多应用的自动化流，如事件触发时发 Slack 消息或新增 Google Sheet 行；每月最多 5,000 个任务免费。
- [back4app.com](https://www.back4app.com) — 基于 Parse Platform 的易用、灵活、可扩展后端。
- [backendless.com](https://backendless.com/) — 移动与 Web BaaS：免费 1GB 文件存储、每月 50,000 条推送、表内 1,000 个数据对象。
- [connectycube.com](https://connectycube.com) — 聊天消息、P2P 音视频通话、文件附件与推送通知不限量；1,000 用户以内应用免费。
- [convex.dev](https://convex.dev/) — 响应式后端即服务：托管数据（带关系与可序列化 ACID 事务的文档）、serverless 函数与向多类客户端推送更新的 WebSockets；小型项目免费——最多 100 万条记录、每月 500 万次函数调用。
- [ETLR](https://etlr.io) — 用 YAML 定义、版本化与部署自动化脚本；面向开发者的拖拽工具替代方案，可用于定时任务、AI Agent 与基础设施监控；免费档每月 100 credits。
- [Flutter Flow](https://flutterflow.io) — 不写一行代码构建 Flutter App UI，另含 Firebase 集成；免费方案含 UI Builder 全部功能与免费模板。
- [getstream.io](https://getstream.io/) — 几小时而非几周内，构建可扩展的应用内聊天、消息、音视频与信息流（Feeds）。
- [IFTTT](https://ifttt.com) — 自动化你常用的应用与设备；免费 2 个 Applet。
- [Integrately](https://integrately.com) — 一键自动化繁琐任务；免费 100 个任务、间隔 15 分钟。
- [LeanCloud](https://leancloud.app/) — 移动后端；免费 1GB 数据存储、256MB 实例、每天 3K API 请求、每天 10K 推送（API 与 Parse Platform 非常相似）。
- [nhost.io](https://nhost.io) — Web 与移动应用的 serverless 后端；免费方案含 PostgreSQL、GraphQL (Hasura)、认证、存储与 Serverless 函数。
- [onesignal.com](https://onesignal.com/) — 不限量免费推送通知；每月 10,000 封邮件，联系人数量不限，含 Auto Warm Up。
- [paraio.com](https://paraio.com) — 后端服务 API：灵活认证、全文搜索与缓存；1 个应用、1GB 应用数据免费。
- [pubnub.com](https://www.pubnub.com/) — 免费推送通知：每月最多 100 万条消息、100 台日活设备。
- [pusher.com](https://pusher.com/beams) — 2,000 名月活用户的免费不限量推送；iOS 与 Android 单一 API。
- [simperium.com](https://simperium.com/) — 数据即时、自动地在多平台随处流动；结构化数据发送与存储不限量，最多 2,500 用户/月。
- [snill.ai](https://snill.ai) — AI 无代码平台：把自然语言描述变成完整业务系统，含关系数据库、仪表盘、工作流、REST API 与 webhooks；单人运营免费方案含 2 个应用、1,000 条记录、每天 10 次 AI 请求。
- [Supabase](https://supabase.com) — 开源 Firebase 替代品，用于构建后端；免费方案提供认证、实时数据库与对象存储。
- [tyk.io](https://tyk.io/) — API 管理：认证、配额、监控与分析；有免费云服务。
- [zapier.com](https://zapier.com/) — 连接你使用的应用以自动化任务：每 15 分钟 5 个 zap、每月 100 个任务、5 个活跃自动化、webhooks。


## 基础设施即服务（IaaS）

- [4EVERLAND](https://www.4everland.org/) — 兼容 AWS S3 的 API、界面操作、CLI 等上传方式，安全便捷高效地把文件上传存储到 IPFS 与 Arweave 网络；注册用户免费得 6GB IPFS 存储与 300MB Arweave 存储；小于 150KB 的 Arweave 文件上传免费。
- [backblaze.com](https://www.backblaze.com/b2/) — Backblaze B2 云存储：免费 10GB（类 Amazon S3）对象存储，时长不限。
- [filebase.com](https://filebase.com/) — 基于区块链的 S3 兼容对象存储；5GB 免费存储，时长不限。
- [Modal](https://modal.com) — AI 驱动 IaaS，算力与存储慷慨；每月 $30 免费额度（部分账户可能限 $5）。
