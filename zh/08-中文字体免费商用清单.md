# 中文字体免费商用清单（可验证版）

> 整理时间：2026-09-06。仅收录**可免费商用**的中文字体，每条附官方授权出处，可点链接自行验证。
> 授权边界以各官方页面**现行文本**为准；本清单是检索索引，不是法律意见。
> 最核心的一句话：**"免费下载" ≠ "免费商用"**，本清单只收录有明确授权声明可商用的字体。

## 一、开源协议类（最省心：可商用 + 可改 + 可再分发，需遵守协议条款）

这类字体采用 SIL OFL 1.1 等开源许可证发布，授权文本公开可查，是**独立开发者和自媒体的首选**——做 App 嵌入、Web Font、商标、出版物基本无障碍（OFL 允许商用与嵌入）。

### 1. 思源黑体 / Source Han Sans（Noto Sans CJK）

- **授权**：SIL Open Font License 1.1（v1.001 及更早为 Apache 2.0；v1.002 起为 OFL 1.1）
- **出品**：Adobe × Google，2014 年发布，7 个字重，覆盖简繁日韩 + 拉丁/希腊/西里尔
- **官方来源**：<https://github.com/adobe-fonts/source-han-sans>（维基百科许可证说明：<https://en.wikipedia.org/wiki/Source_Han_Sans>）
- **适用**：UI、正文、PPT、电商图、屏幕显示
- **注意**：衍生字体须以同样 OFL 协议发布；禁止单独出售字体文件

### 2. 思源宋体 / Source Han Serif（Noto Serif CJK）

- **授权**：SIL OFL 1.1
- **出品**：Adobe × Google，2017 年发布，7 个字重，思源黑体的衬线配套
- **官方来源**：<https://github.com/adobe-fonts/source-han-serif>
- **适用**：书籍排版、正文、需要"纸感/书卷气"的场景

### 3. 霞鹜文楷 / LXGW WenKai

- **授权**：SIL OFL 1.1（基于 FONTWORKS 的 Klee 开源项目改造）
- **出品**：个人开发者落霞孤鹜（lxgw），简体字库补全 GB 2312 共 6763 字，另有 GB/TC/屏显加粗等衍生版本
- **官方来源**：<https://github.com/lxgw/LxgwWenKai>
- **适用**：公众号排版、手写质感正文、电子书、PPT 标题
- **注意**：衍生字体**不得使用保留名称**「霞鹜」「LXGW」；禁止单独出售字体文件；同协议下衍生字体须继续开源

### 4. 得意黑 / Smiley Sans

- **授权**：SIL OFL 1.1
- **出品**：atelier-anchor 锚坞 × B 站 UP 主 oooooohmygosh，2022 年发布，6° 倾斜人文黑体，v2.0.1（2024-02）
- **官方来源**：<https://github.com/atelier-anchor/smiley-sans>
- **适用**：视频封面、海报标题、潮流感设计字（B 站/短视频封面高频使用）
- **注意**：单字重偏标题向；禁止单独出售字体文件

### 5. jf open 粉圆（台湾繁体向）

- **授权**：SIL OFL 1.1
- **出品**：台湾 justfont 基于小杉圆体（Kosugi Maru）改作，补台湾常用字/注音/台客语拼音
- **官方来源**：<https://github.com/justfont/open-huninn-font>
- **适用**：圆体风格标题/UI，繁体场景友好
- **注意**：整体偏繁体字形，简体用户请确认字形是否符合需要

### 6. 芫荽 / Iansui（台湾繁体向）

- **授权**：SIL OFL 1.1
- **出品**：ButTaiwan，台湾第一套开源硬笔楷书，基于 Klee One
- **官方来源**：<https://github.com/ButTaiwan/iansui>
- **适用**：教育、手写感繁体排版

> 同源的更多台湾开源衍生（均 OFL 1.1，繁体向）：昭源黑体（chiron-fonts，基于思源改良）、源样黑体/源样明体/源泉圆体/源流明体/源云明体（ButTaiwan 系列）——可到各 GitHub 项目页确认授权文件后使用。

## 二、厂商免费商用类（免费，但需逐条看授权条款）

这类是**厂商授权声明免费商用**，不是 OSI 开源协议。共同特点：**不可修改/二次开发字体本身，不可单独转售/再分发字体文件**；但用字体创作的作品（海报、App、logo 等）可自由分发出售。差异点在"能否嵌入、能否做商标、是否须署名"，逐条列出。

- **官方授权文本**（2.0 版权说明，iconfont 官方页）：<https://www.iconfont.cn/fonts/detail?cnid=adI1E7HF7yme>
- **官方下载页**：<https://www.alibabafonts.com/#/font>

- **注意**：不可修改/仿制/反编译字体；不可上传转载字体文件；不可出售/出租字体本身。第三方整理的授权表格（如字库星球）标注"全媒体+商标+嵌入均可"，**但以官方授权文本为准，涉及商标/嵌入前建议通过官网渠道确认**

## 三、⚠️ 有条件免费：方正字库"免费款"（最容易踩坑）

方正官网明确**商业发布可免费使用**的字体：**方正黑体、方正书宋、方正仿宋、方正楷体**（字加平台另列方正甲骨文，共 5 款；人民日报相关报道口径为黑体/书宋/仿宋/楷体 4 款，以官网为准）。

- **官方说明**（方正字库官网-字加）：<https://www.foundertype.com/index.php/FontInfo/index/id/6015.html>；人民日报人民号对免费范围的口径：<https://www.peopleapp.com/rmharticle/30016550380>
- **免费范围（仅限"商业发布"）**：广告类（平面/户外/视频/网络广告、Banner、海报）、VI 类（logo、宣传语、标准字）、手册资料、影视作品、网络店铺、新媒体（微信/微博）、实物产品包装、企业官网等
- **⚠️ 不支持的场景（需要另行付费授权）**：
  1. **嵌入式用途**：游戏图片/嵌入、App 嵌入（把字体文件整体嵌入 iOS/安卓等应用）、车载设备、硬件、电子阅读器
  2. **Web Font**：通过 CSS 网页调用（在线云字库）
  3. **商标注册、出版物发行**等超出"商业发布"定义的场景
- **对你（独立开发者）最关键的提醒**：如果你做的 App 要把字体文件打包嵌入、或网站要 @font-face 调用方正这几款——**都不在免费范围内**。做产品内嵌字体，优先选第一节的 OFL 字体（思源/霞鹜/得意黑），授权边界干净得多。

## 四、避坑速查（自媒体 + 独立开发者视角）

1. **免费下载 ≠ 免费商用**：dafont 等站同站字体授权混杂（freeware/shareware/demo/公有领域），逐款看授权文件；demo 版商用即侵权。
2. **国内字体侵权判赔参考**：据中国新闻网报道，国内字体侵权相关案件 10 年翻 100 倍，遭遇侵权问题的电商卖家平均每款字体赔偿约 4500 元（出处：<https://m.chinanews.com/wap/detail/chs/zw/9477244.shtml>）。字体虽小，累计起来是实打实的成本。
3. **三个高危场景**：① App/软件**嵌入字体文件** ② 网站 **Web Font 调用** ③ **商标注册用字**——这三类即使在"免费商用"字体里也要逐条核对授权文本是否覆盖。
4. **验证方法**：别信转载站的"免费"标签，去**字体官网/官方 GitHub/官方授权文本页**查授权声明；不确定就发邮件问版权方要书面确认（阿里普惠体官方就表示可配合出具授权书）。
5. **开源协议字体（OFL）的一般权利**：个人/企业均可免费商用、可嵌入、可修改（衍生须同协议开源）、可与软件捆绑销售；**唯独不能单独售卖字体文件本身**，衍生字体不能用原字体保留名称。
6. **缺字/字形问题**：简体中文日常使用优先选覆盖 GB2312/GB18030 的版本；思源系列分"简体中文版"与"日文版"等不同字形区域，安装时注意选对语言版本，避免"门""骨"等字形不符。
