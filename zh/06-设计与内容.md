## 设计与 UI（Design and UI）

- [Beste](https://beste.co) — 基于 shadcn/ui 块的"组合优先"网站构建器。免费版可连自己的自定义域名，含页面不限、多语言、博客、表单与托管
- [BoxySVG](https://boxy-svg.com) — 免费可安装 Web 应用：绘制 SVG 并导出为 SVG、PNG、jpeg 等格式
- [BrandIcons](https://brandicons.dev) — Favicon API：针对无图标甚至无 Web 服务器的域名做 AI 发现。免费档注明出处后每月 50 万次请求
- [Calendar Icons Generator](https://calendariconsgenerator.app/) — 一次点击生成全年份的独特图标，完全免费
- [Canva](https://canva.com) — 免费在线设计工具，创建视觉内容
- [CodedThemes](https://codedthemes.com/) — 提供制作精良的后台仪表盘与 UI 套件，简化加速现代 Web 开发
- [Excalidraw](https://excalidraw.com/) — 免费在线绘图文档网页，支持免费存本地与导出
- [figma.com](https://www.figma.com) — 面向团队的在线协作设计工具。免费档含文件与查看者不限，最多 2 名编辑者、3 个项目
- [Flows](https://flows.sh/) — 完全可定制产品采用平台：构建引导与用户互动体验。每月最多 250 名被追踪用户免费
- [JoyDemo](https://joydemo.com) — 为网站或应用创建可交互、可点击的演示。免费：演示不限、观看次数不限
- [landen.co](https://www.landen.co) — 无代码为创业项目生成、编辑、发布精美网站与落地页。免费档 1 个网站，完全可定制并发布到互联网
- [lensdump.com](https://lensdump.com/) — 免费云图片托管
- [Logo.dev](https://www.logo.dev) — 公司 logo API：4400 万+ 品牌，调用 URL 一样简单。前 1 万次 API 调用免费
- [marvelapp.com](https://marvelapp.com/) — 设计、原型与协作，免费版限 1 用户与 1 项目
- [Mindmup.com](https://www.mindmup.com/) — 无限思维导图免费，云端存储，任何设备即时访问
- [Mockplus iDoc](https://www.mockplus.com/idoc) — 强大的设计协作与交付工具。免费版含 3 用户与 5 个项目，功能齐全
- [photopea.com](https://www.photopea.com) — 免费高级在线设计编辑器，Adobe Photoshop UI，支持 PSD、XCF 与 Sketch 格式
- [Plasmic](https://www.plasmic.app/) — 快速、易用、稳健的 Web 设计工具与页面构建器，可集成进代码库：构建响应式页面或复杂组件，可选代码扩展，发布到生产站点与应用
- [Proto.io](https://www.proto.io) — 无编码创建完全交互的 UI 原型。免费试用结束后有免费档：1 用户、1 项目、5 个原型、100MB 在线存储与 proto.io 应用预览
- [Quant Ux](https://quant-ux.com/) — 原型与设计工具，完全免费且开源
- [Shadcn Studio](https://shadcnstudio.com/theme-editor) — 在不同组件与布局中预览主题改动
- [smartmockups.com](https://smartmockups.com/) — 创建产品样机，200 个免费样机
- [SVGicons.com](https://svgicons.com/) — 31.2 万+ 开源 SVG 图标的免费搜索引擎，提供即用的 SVG、React、Vue、HTML 与 CSS 代码
- [TeleportHQ](https://teleporthq.io/) — 低代码前端设计与开发平台：即时创建并发布 Headless 静态网站的协作前端平台。3 个免费项目、协作者不限、免费导出代码
- [Unicorn Platform](https://unicornplatform.com/) — 省心的落地页构建器，含托管。1 个网站免费
- [Updrafts.app](https://updrafts.app) — 面向 tailwindcss 设计的所见即所得网站构建器。非商业使用免费
- [Webflow](https://webflow.com) — 所见即所得网站构建器：动画与网站托管。2 个项目免费
- [Webstudio](https://webstudio.is/) — Webflow 的开源替代品。免费版：其域名下网站不限；自定义域名 5 个网站；每月 1 万次页面浏览；2GB 资产存储
- [whimsical.com](https://whimsical.com/) — 协作流程图、线框图、便签与思维导图。最多免费创建 4 块画板
- [Zeplin](https://zeplin.io/) — 设计师与开发者协作平台：展示设计、资产与风格指南。1 个项目免费
- [WrapPixel](https://www.wrappixel.com/) — 下载用 Angular、React、VueJs、NextJS 与 NuxtJS 制作的高质量免费与高级后台仪表盘模板！用 HTML 主题与 UI 套件更快构建应用
- [Themeselection](https://themeselection.com/) — 精选高质量、现代设计、专业易用的免费后台仪表盘模板
- [AdminMart](https://adminmart.com/) — 用 Angular、Bootstrap、React、VueJs、NextJS 与 NuxtJS 制作的高质量免费与高级后台仪表盘及网站模板


## 字体（Font）

- [Befonts](https://befonts.com/) — 提供多款独特字体，个人或商业使用均可。
- [Bunny](https://fonts.bunny.net) — 隐私优先的 Google Fonts 替代。
- [dafont](https://www.dafont.com/) — 本站展示的字体归其作者所有，授权为免费软件、共享软件、演示版或公有领域。
- [Everything Fonts](https://everythingfonts.com/) — 提供多种工具：@font-face、单位转换器、字体 Hint 器与字体提交器。
- [Font of web](https://fontofweb.com/) — 识别网站上使用的全部字体及其使用方式。
- [Font Squirrel](https://www.fontsquirrel.com/) — 已授权可用于商业工作的免费字体，人工精选并以易用格式呈现。
- [FontGet](https://www.fontget.com/) — 提供多种字体下载，用标签整洁分类。
- [fonts.xz.style](https://fonts.xz.style/) — 免费开源服务，通过 CSS 向网站交付字体族。
- [Fontsensei](https://fontsensei.com/) — 由用户打标签的开源 Google 字体，含 CJK（中日韩）字体标签。
- [Fontshare](https://www.fontshare.com/) — 免费字体服务。持续增长的专业级字体合集，个人与商业使用 100% 免费。
- [Google Fonts](https://fonts.google.com/) — 许多免费字体可通过下载或链接 Google CDN 轻松快速安装到网站。


## 开发者博客（Dev Blogging Sites）

- [AyeDot](https://ayedot.com/) — 免费以现代多媒体短格式 Miniblog 与世界分享想法、知识与故事
- [BearBlog](https://bearblog.dev/) — 极简、Markdown 驱动的博客与网站构建器
- [Dev.to](https://dev.to/) — 程序员分享想法、互相成长的地方
- [Hashnode](https://hashnode.com/) — 面向开发者的省心博客软件
- [Medium](https://medium.com/) — 对你重要的事多想一层
- [JustBlogged](https://justblogged.com) — 免费博客平台：支持自定义域名，全球访问快速


## 评论平台（Commenting Platforms）

- [GraphComment](https://graphcomment.com/) — 评论平台：帮网站把访客转化为活跃社区
- [IntenseDebate](https://intensedebate.com/) — 功能丰富的评论系统：支持 WordPress、Tumblr、Blogger 与众多其他网站平台
- [Remarkbox](https://www.remarkbox.com/) — 开源托管评论平台，"少数域名上一个版主、行为与外观完全可控"，按能力付费
- [Utterances](https://utteranc.es/) — 基于 GitHub issues 的轻量评论组件：用 GitHub issues 承载博客评论、wiki 页面等


## 杂项（Miscellaneous）

- [BinShare.net](https://binshare.net) — 创建与分享代码或二进制：可分享为美观图片（如用于 Twitter/Facebook）或以链接分享（如用于聊天或论坛）
- [Blynk](https://blynk.io) — 带 API 的 SaaS：控制、构建与评估 IoT 设备。免费开发者计划：5 台设备、免费云与数据存储，另有移动应用
- [cron-job.org](https://cron-job.org) — 在线 cron 任务服务，不限量任务免费
- [Cronhooks](https://cronhooks.io/) — 定时一次性或循环 webhook。免费版允许 5 个临时调度
- [datelist.io](https://datelist.io) — 在线预订/预约排程系统。每月最多 5 次预订免费，含 1 个日历
- [FOSSA](https://fossa.com/) — 可扩展的第三方代码端到端管理：许可证合规与漏洞
- [Hook Relay](https://www.hookrelay.dev/) — 零负担为你的应用加 webhook：现成队列、退避重试与日志。免费版每天 100 次投递、14 天保留、3 个 hook 端点
- [Hosting Checker](https://hostingchecker.co) — 查询任意域名/网站/IP 的托管信息（ASN、ISP、位置等），另有多个托管与 DNS 相关工具
- [newreleases.io](https://newreleases.io/) — 接收 GitHub、GitLab、Bitbucket、Python PyPI、Java Maven、Node.js NPM、Node.js Yarn、Ruby Gems、PHP Packagist、.NET NuGet、Rust Cargo 与 Docker Hub 的新版本通知，可发到邮件、Slack、Telegram、Discord 与自定义 webhook
- [PDFMonkey](https://www.pdfmonkey.io/) — 在仪表盘管理 PDF 模板，用动态数据调用 API，下载 PDF。每月 300 份免费文档
- [Pika Code Screenshots](https://pika.style/templates/code-image) — 用扩展从代码片段与 VSCode 生成美观、可定制的截图
- [QuickType.io](https://quicktype.io/) — 从 JSON、schema 与 GraphQL 快速自动生成模型/类/类型/接口与序列化器，在任何语言中安全快速处理数据；把 JSON 转成任意语言的漂亮类型安全代码
- [readme.com](https://readme.com/) — 轻松做出漂亮的文档，开源项目免费
- [redirect.pizza](https://redirect.pizza/) — 轻松管理重定向，支持 HTTPS。免费版含 10 个来源、每月 10 万次访问
- [redirection.io](https://redirection.io/) — 面向企业、营销与 SEO 的 HTTP 重定向管理 SaaS 工具
- [redirs.com](https://www.redirs.com/) — 简单域名重定向：自动 SSL、分析与 URL 路径转发。基础使用免费（最多 5 个域名）
- [RedirHub](https://www.redirhub.com/) — API 优先的 URL 重定向基础设施：自定义 nameserver、边缘网络、HTTPS 与主动链接监控。免费版含 2 个主机名、每月 10 万次请求、自动 SSL、路径转发与 REST API 访问
- [ReqBin](https://reqbin.com/) — 在线发送 HTTP 请求：支持 GET、POST、PUT、DELETE 与 HEAD，支持 Headers 与 Token 认证，含基本登录系统用于保存请求
- [Smartcar API](https://smartcar.com) — 面向汽车的 API：定位、油量/电量、里程表、开关门锁等
- [Sunrise and Sunset](https://sunrisesunset.io/api/) — 按经纬度获取日出日落时间
- [superfeedr.com](https://superfeedr.com/) — 实时、兼容 PubSubHubbub 的 feed：导出与分析。免费版定制项较少
- [SurveyMonkey.com](https://www.surveymonkey.com) — 创建在线问卷并在线分析结果。免费版每份问卷仅 10 个问题、100 条响应
- [SYNCDATE](https://syncdate.app) — 双向 Google 日历同步。免费档：2 个账号、事件不限
- [UUID Generator](https://newuuid.com/) — 即时生成企业级 UUID v1、UUID v4、UUID v7、GUID、Nil UUID、CUID v1/v2、NanoID 与 ULID
- [Versionfeeds](https://versionfeeds.com) — 为你心爱软件版本发布定制的 RSS feed：把编程语言、库或喜爱工具的最新版本聚合到一个 feed（前 3 个 feed 免费）


## 其他免费资源（Other Free Resources）

- [get.localhost.direct](https://get.localhost.direct) — 更好的 `*.localhost.direct` 通配符公共 CA 签名 SSL 证书：本地开发用，支持子域名
- [GitHub Education](https://education.github.com/pack) — 面向学生的免费服务合集，需注册
- [Glob tester](https://globster.xyz/) — 设计与测试 glob 模式的网站，也提供学习 glob 模式的资料
- [Killer Coda](https://killercoda.com/) — 浏览器内交互式 playground：学习 Linux、Kubernetes、容器、编程、DevOps、网络
- [Microsoft 365 Developer Program](https://developer.microsoft.com/microsoft-365/dev-program) — 免费获取为 Microsoft 365 平台构建方案所需的沙箱、工具与其他资源。订阅为可续期的 90 天 [Microsoft 365 E5 订阅](https://www.microsoft.com/microsoft-365/enterprise/e5)（不含 Windows）；活跃开发（按遥测数据与算法衡量）即可续期
- [MySQL Visual Explain](https://mysqlexplain.com) — 通俗易懂的免费 MySQL EXPLAIN 输出可视化工具，用于优化慢查询
- [RedHat for Developers](https://developers.redhat.com) — 开发者专享的 Red Hat 产品免费访问（RHEL、OpenShift、CodeReady 等），仅个人计划；另提供免费电子书参考
- [sandbox.httpsms.com](https://sandbox.httpsms.com) — 免费发送与接收测试短信
- [SimpleBackups.com](https://simplebackups.com/) — 服务器与数据库（MySQL、PostgreSQL、MongoDB）备份自动化，直接存入云存储（AWS、DigitalOcean、Backblaze）。免费版含 1 份备份
- [SimpleRestore](https://simplerestore.io) — 省心的 MySQL 备份恢复：无需代码或服务器，把 MySQL 备份恢复到任意远程数据库
- [SnapShooter](https://snapshooter.com/) — 面向 DigitalOcean、AWS、LightSail、Hetzner 与 Exoscale 的备份方案：支持把数据库、文件系统与应用直接备份到 s3 存储。免费版含 1 个资源的每日备份
