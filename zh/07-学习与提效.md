## 翻译管理（Translation Management）

- [AutoLocalise.com](https://www.autolocalise.com/) — 无需管理翻译文件即可即时本地化。每月最多 10,000 字符免费，语言不限。
- [crowdin.com](https://crowdin.com/) — 开源项目：项目、字符串与协作者数量均不限。
- [Free PO editor](https://pofile.net/free-po-editor) — 对所有人免费。
- [Lingo.dev](https://lingo.dev) — 开源的 AI 驱动 CLI，用于 Web 与移动本地化。可自带 LLM，也可通过 Lingo.dev 托管的本地化引擎每月免费使用 10,000 词。
- [lingohub.com](https://lingohub.com/) — 最多 3 个用户免费，开源项目永久免费。
- [Localhero.ai](https://localhero.ai) — 每次 pull request 自动生成贴合品牌的翻译，带术语表与翻译记忆。1 个项目免费，每月 250 个翻译积分（约 4,000 词）。
- [localazy.com](https://localazy.com) — 1,000 个源语言字符串免费，语言与贡献者不限，另有 startup 与开源优惠。
- [Localit](https://localit.io) — 快速、开发者友好的本地化平台，无缝集成 GitHub/GitLab（免费），支持 AI 辅助与人工翻译。慷慨的免费方案：2 个用户、500 个 key、项目数不限。
- [localizely.com](https://localizely.com/) — 开源项目免费。
- [Loco](https://localise.biz/) — 最多 2,000 条翻译免费，译者不限，每项目 10 种语言、1,000 个可翻译资源。
- [POEditor](https://poeditor.com/) — 最多 1,000 个字符串免费。
- [SimpleLocalize](https://simplelocalize.io/) — 最多 100 个翻译 key 免费，字符串与语言不限，另有 startup 优惠。
- [Texterify](https://texterify.com/) — 单用户免费。
- [Tolgee](https://tolgee.io) — 免费 SaaS（翻译量有限），另有永久免费的自托管版本。
- [transifex.com](https://www.transifex.com/) — 开源项目免费。


## 教育求职（Education and Career Development）

- [Cisco Networking Academy, Skills for All](https://skillsforall.com/) — 提供免费的认证对齐课程，涵盖网络安全、网络与 Python 等主题。
- [CloudCertPrep](https://cloudcertprep.io) — 免费、开源的 AWS 认证模拟考试，含 1,050+ 道 CLF-C02 题目。提供限时模拟考、按领域练习、间隔重复与进度追踪。
- [CodeTrain](https://codetrain.ai) — AI 编程导师，在你的代码库上教学且从不替你写代码。免费档：每月 10 节浏览器内课程，Python/JS 在客户端运行，无需银行卡。
- [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/) — 行业顶尖专家的免费短课程，在一小时以内上手最新生成式 AI 工具与技术。
- [DevNet Academy](https://devnet-academy.com/) — 面向 Cisco DevNet Expert / CCIE Automation 认证的免费自定进度培训，涵盖 Python Click 与 Flask-RESTx。
- [Django-tutorial.dev](https://django-tutorial.dev) — 免费在线指南，把 Django 作为第一个框架来学习；并向用户撰写的文章提供免费的 dofollow 反向链接。
- [edX](https://www.edx.org/) — 提供 250 所顶尖机构（含哈佛、MIT）的 4,000+ 门免费在线课程，专注于计算机科学、工程与数据科学。
- [Exercism](https://exercism.org) — 免费、开源的编程教育，覆盖 75+ 种编程语言，带真人导师。非营利组织。
- [Free Professional Resume Templates & Editor](https://www.overleaf.com/latex/templates/tagged/cv) — 免费平台，提供大量资深专业人士的简历模板，可克隆、完整编辑并下载，ATS 优化。
- [FreeCodeCamp](https://www.freecodecamp.org/) — 开源平台，提供数据分析、信息安全、Web 开发等方向的免费课程与认证。
- [Full Stack Open](https://fullstackopen.com/en/) — 免费的大学级现代 Web 开发课程：React、Node.js、GraphQL、TypeScript 等，全在线、自定进度。
- [Interactive CV](https://interactive-cv.com) — AI 驱动的简历生成器，实时编辑与 ATS 优化。免费档含：自动将 CV 转为高级模板（Harvard、Europass）、PDF 导出、无限职位洞察的职位追踪器、带聊天/语音功能的简历分享。
- [Khan Academy](https://www.khanacademy.org/computing/computer-programming) — 免费在线指南，学习基础到高级的 HTML/CSS、JavaScript 与 SQL。
- [LabEx](https://labex.io) — 通过交互式实验室与真实项目，培养 Linux、DevOps、网络安全、编程、数据科学等技能。
- [MIT OpenCourseWare](https://ocw.mit.edu/) — 在线发布 2,500+ 门 MIT 课程的资料，向全球学习者与教育者免费分享知识。YouTube 频道见 [@mitocw](https://www.youtube.com/@mitocw/featured)。
- [Reactive Resume](https://rxresu.me) — 免费、开源的简历生成器，含数十种模板。可导出 PDF、DOCX，并可提供可公开分享的简历链接（可选开启）。
- [Roadmap.sh](https://roadmap.sh) — 免费学习路线图，覆盖从区块链到 UX 设计的开发方方面面。
- [The Odin Project](https://www.theodinproject.com/) — 免费、开源平台，课程聚焦 JavaScript 与 Ruby 的 Web 开发。
- [W3Schools](https://www.w3schools.com/) — 提供 HTML、CSS、JavaScript 等 Web 开发技术的免费教程。
- [WebTerm Learn](https://learn.webterm.app) — 在浏览器内的模拟终端里学习 Linux 终端、Git 与 Vim。全部 129 节课免费；每门课程的第一课无需账号。


## 低代码平台（Low-code Platform）

- [appsmith](https://www.appsmith.com/) — 低代码项目，用于构建管理后台、内部工具与仪表盘。集成 15+ 数据库与任意 API。
- [BudiBase](https://budibase.com/) — Budibase 是开源低代码平台，几分钟内创建内部应用。支持 PostgreSQL、MySQL、MSSQL、MongoDB、REST API、Docker、K8s。
- [Clappia](https://www.clappia.com) — 面向业务流程应用的低代码平台，可定制移动与 Web 应用。提供拖拽界面、离线支持、实时位置追踪以及与多种第三方服务集成等功能。
- [lil'bots](https://www.lilbots.io/) — 在线编写与运行脚本，利用内置的免费 API（OpenAI、Anthropic、Firecrawl 等）。非常适合构建 AI agent / 内部工具并与团队分享。免费档含全部 API 访问、AI 编程助手与每月 10,000 次执行积分。
- [manubes](https://www.manubes.com) — 强大的无代码云平台，聚焦工业产线管理。1 个用户免费，每月 100 万次工作流活动（另有德语版 [manubes.de](https://www.manubes.de)）。
- [Mendix](https://www.mendix.com/) — 面向企业的快速应用开发平台：无限可访问的沙箱环境，支持全部用户，每应用 0.5 GB 存储与 1 GB 内存。Studio 与 Studio Pro IDE 也允许在免费档使用。
- [outsystems.com](https://www.outsystems.com/) — 面向本地或云端的企业 Web 开发 PaaS，免费"个人环境"允许无限代码与最多 1 GB 数据库。
- [ReTool](https://retool.com/) — 构建内部应用的低代码平台。Retool 高度可定制：凡能用 JavaScript + API 写出来的，就能在 Retool 中实现。免费档每月最多 5 个用户，应用与 API 连接数不限。
- [ToolJet](https://www.tooljet.com/) — 可扩展的低代码框架，用于构建业务应用。可连接数据库、云存储、GraphQL、API 端点、Airtable 等，并用拖拽式应用构建器搭建应用。
- [UI Bakery](https://uibakery.io) — 低代码平台，更快构建自定义 Web 应用。通过拖拽构建 UI，并可用 JavaScript、Python 与 SQL 高度定制。提供云端与自托管两种方案，最多 5 个用户免费。
