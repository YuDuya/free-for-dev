## 代码托管（Source Code Repos）

- [Bitbucket](https://bitbucket.org/) — 最多 5 名用户，公共与私有 Git 仓库不限量，含 Pipelines CI/CD。
- [Codeberg](https://codeberg.org/) — 自由与开源项目可享公共/私有 Git 仓库不限量（协作者不限），由 [Forgejo](https://forgejo.org/) 驱动；附 [Codeberg Pages](https://codeberg.page/) 静态网站托管、[Codeberg CI](https://docs.codeberg.org/ci/)、[Codeberg Translate](https://translate.codeberg.org/) 翻译托管；还含包与容器托管、项目管理与问题跟踪。
- [framagit.org](https://framagit.org/) — Framasoft 基于 GitLab 软件的自建软件锻造厂：含 CI、静态页面、项目页与问题跟踪。
- [GitGud](https://gitgud.io) — 公共与私有仓库均不限量，永久免费；基于 GitLab 与 Sapphire；含 CI/CD、静态托管、容器注册表、项目管理与问题跟踪。
- [GitHub](https://github.com/) — 公共与私有仓库（协作者不限）均不限量；含 CI/CD、开发环境、静态托管、包与容器托管、项目管理与 AI Copilot。
- [gitlab.com](https://about.gitlab.com/) — 最多 5 名协作者的公共/私有 Git 仓库不限量；含 CI/CD、静态托管、容器注册表、项目管理与问题跟踪。
- [heptapod.net](https://foss.heptapod.net/) — GitLab 社区版的友好分支，提供 Mercurial 支持。
- [pijul.com](https://pijul.com/) — 自由开源的分布式版本控制系统，使用不限量；特色是建立在严谨的补丁理论之上，易学易用易分发，解决 git/hg/svn/darcs 的诸多问题。
- [projectlocker.com](https://projectlocker.com) — 1 个免费私有项目（Git 与 Subversion），50MB 空间。
- [RocketGit](https://rocketgit.com) — 基于 Git 的仓库托管，公共与私有仓库均不限量。
- [savannah.gnu.org](https://savannah.gnu.org/) — 面向自由软件项目（GNU 项目）的协作软件开发管理系统。
- [savannah.nongnu.org](https://savannah.nongnu.org/) — 面向自由软件项目（非 GNU 项目）的协作软件开发管理系统。


## 制品仓库（Artifact Repos）

- [Gemfury](https://gemfury.com) — 支持 Maven、PyPi、NPM、Go Module、Nuget、APT、RPM 的私有/公共制品仓库；公共项目免费。
- [jitpack.io](https://jitpack.io/) — GitHub 上 JVM 与 Android 项目的 Maven 仓库；公共项目免费。
- [paperspace](https://www.paperspace.com/) — 构建与扩展 AI 模型，开发、训练与部署 AI 应用；免费方案：公共项目、5GB 存储、基础实例。
- [RepoFlow](https://repoflow.io) — 简化包管理，支持 npm、PyPI、Docker、Go、Helm 等；云上免费试用含 10GB 存储、10GB 带宽、100 个包、用户不限；也可仅限个人自托管。
- [RepoForge](https://repoforge.io) — 云托管私有仓库，支持 Python、Debian、NPM 包与 Docker 注册表；开源/公共项目有免费方案。
- [repsy.io](https://repsy.io) — 1GB 免费私有/公共 Maven 仓库。


## 代码生成（Code Generation）

- [Appinvento](https://appinvento.io/) — 免费无代码应用构建器：完整开放自动生成的后端源代码，API 与路由不限量；免费方案含 3 个项目与 5 张表。
- [DhiWise](https://www.dhiwise.com/) — 把 Figma 设计稿转换为可运行的 Flutter 与 React 应用；其代码生成技术面向生产级移动与 Web 体验的工作流优化。
- [Karbon Sites](https://www.karbonsites.space) — AI 驱动的建站与编辑器：从文本提示、草图或简历生成生产级前端代码；支持原生 Android（APK）导出；免费档每月 5 次生成（用自定义 Gemini API key 可不限量）。
- [Metalama](https://www.postsharp.net/metalama) — C# 专用工具，在编译期即时生成样板代码以保持源码整洁；开源项目免费，商用友好的免费档最多含 3 个 aspect。
- [Supermaven](https://www.supermaven.com/) — 面向 VS Code、JetBrains、Neovim 的高速 AI 代码补全插件；免费档内联补全不限量，主打超低延迟。
- [v0.dev](https://v0.dev/) — Vercel 出品，用 shadcn/ui 与 Tailwind CSS 生成可直接复制粘贴的 React 代码；按积分制：初始 1,200 积分 + 每月 200 免费积分。


## 代码质量（Code Quality）

- [beanstalkapp.com](https://beanstalkapp.com/) — 覆盖编写、评审、部署代码的完整工作流；免费账号限 1 名用户、1 个仓库、100MB 存储。
- [codacy.com](https://www.codacy.com/) — 面向 PHP、Python、Ruby、Java、JavaScript、Scala、CSS、CoffeeScript 的自动化代码评审；公共与私有仓库均不限量，免费。
- [Codeac.io](https://www.codeac.io/infrastructure-as-code.html?ref=free-for-dev) — 面向 DevOps 的自动化 IaC（基础设施即代码）评审工具，集成 GitHub、Bitbucket、GitLab（含自托管）；除常规语言外还分析 Ansible、Terraform、CloudFormation、Kubernetes 等（开源免费）。
- [codecov.io](https://codecov.io/) — 代码覆盖率工具（SaaS）；开源项目免费，另含 1 个免费私有仓库。
- [CodeFactor](https://www.codefactor.io) — Git 自动化代码评审；免费版用户不限、公共仓库不限，外加 1 个私有仓库。
- [coderabbit.ai](https://coderabbit.ai) — 集成 GitHub/GitLab 的 AI 代码评审；免费档每小时 200 个文件、3 次评审、50 轮对话；开源项目永久免费。
- [CodSpeed](https://codspeed.io) — 在 CI 流水线中自动化性能追踪：以精确一致的指标在部署前发现性能回退；开源项目永久免费。
- [coveralls.io](https://coveralls.io/) — 展示测试覆盖率报告；开源免费。
- [deepscan.io](https://deepscan.io) — 高级静态分析，自动发现 JavaScript 代码运行时错误；开源免费。
- [DeepSource](https://deepsource.io/) — 持续分析代码变更，发现并修复安全、性能、反模式、缺陷风险、文档与风格问题；原生集成 GitHub、GitLab、Bitbucket。
- [DiffText](https://difftext.com) — 即时找出两段代码的差异；完全免费。
- [eversql.com](https://www.eversql.com/) — 自称"数据库优化第一平台"：自动获得数据库与 SQL 查询的关键洞察。
- [gerrithub.io](https://review.gerrithub.io/) — 为 GitHub 仓库提供免费的 Gerrit 代码评审。
- [goreportcard.com](https://goreportcard.com/) — Go 项目代码质量报告；开源免费。
- [gtmetrix.com](https://gtmetrix.com/) — 网站优化报告与详尽建议。
- [holistic.dev](https://holistic.dev/) — 自称"PostgreSQL 优化第一静态分析器"：自动检测性能、安全与架构层面的数据库问题。
- [houndci.com](https://houndci.com/) — 在 GitHub 提交上就代码质量发表评论；开源免费。
- [reviewable.io](https://reviewable.io/) — GitHub 仓库代码评审；公共或个人仓库免费。
- [scan.coverity.com](https://scan.coverity.com/) — Java、C/C++、C#、JavaScript 静态代码分析；开源免费。
- [scrutinizer-ci.com](https://scrutinizer-ci.com/) — 持续检查平台；开源免费。
- [semanticdiff.com](https://app.semanticdiff.com/) — 面向 GitHub 拉取请求与提交的编程语言感知 diff；公共仓库免费。
- [shields.io](https://shields.io) — 开源项目的质量元数据徽章。
- [sonarcloud.io](https://sonarcloud.io) — 自动化源码分析，支持 Java、JavaScript、C/C++、C#、VB.NET、PHP、Objective-C、Swift、Python、Groovy 等更多语言；开源免费。


## 代码搜索与浏览（Code Search and Browsing）

- [CodeKeep](https://codekeep.io) — 代码片段的"Google Keep"：组织、发现、分享代码片段，带强大的代码截图工具（预设模板）与链接功能。
- [libraries.io](https://libraries.io/) — 覆盖 32 种包管理器的搜索与依赖更新通知；开源免费。
- [Namae](https://namae.dev/) — 在 GitHub、Gitlab、Heroku、Netlify 等多个网站搜索你的项目名是否可用。
- [tickgit.com](https://www.tickgit.com/) — 定位 `TODO` 注释（及其他标记），找出值得回头改进的代码区域。


## CI / CD

- [appcircle.io](https://appcircle.io) — 企业级移动 DevOps 平台：自动化移动应用的构建、测试与上架发布，加快发布周期。免费：单次构建最多 30 分钟、每月 20 次构建、1 个并发构建。
- [appveyor.com](https://www.appveyor.com/) — Windows 的 CD 服务；开源免费。
- [bitrise.io](https://www.bitrise.io/) — 移动应用（原生或混合）的 CI/CD：每月 200 次免费构建、每次 10 分钟、2 名团队成员；开源项目可享 45 分钟构建、+1 并发、团队规模不限。
- [buddy.works](https://buddy.works/) — CI/CD：5 个免费项目、1 个并发（每月 120 次执行）。
- [Buildkite](https://buildkite.com) — CI 流水线：3 名用户与每月 5k 任务分钟免费；测试分析免费开发者档含每月 10 万次测试执行，开源项目另有更多免费额度。
- [bytebase.com](https://www.bytebase.com/) — 数据库 CI/CD 与 DevOps；20 名用户与 10 个数据库实例以内免费。
- [CircleCI](https://circleci.com/) — 面向 GitHub、GitLab、BitBucket 仓库的托管 CI/CD，免费方案功能全面：多种资源类、Docker、Windows、macOS、ARM 执行器、本地 runner、测试拆分、Docker Layer Caching 等。免费最多每月 6,000 分钟执行、协作者不限、私有项目 30 个并行任务；开源项目最多 80,000 免费构建分钟。
- [cirun.io](https://cirun.io) — 公共 GitHub 仓库免费。
- [codemagic.io](https://codemagic.io/) — 每月免费 500 构建分钟。
- [deployhq.com](https://www.deployhq.com/) — 1 个项目、每天 10 次部署（每月 30 构建分钟）。
- [LocalOps](https://localops.co/) — 30 分钟内把应用部署到 AWS/GCP/Azure；在任何云上搭建标准化应用环境，内置持续部署自动化与高级可观测性。免费方案：1 用户、1 个应用环境。
- [Make](https://www.make.com/en) — 工作流自动化工具：用 UI 连接应用、自动化工作流；支持众多应用与主流 API。公共 GitHub 仓库免费；免费档另有 100Mb、1,000 次操作、最小间隔 15 分钟。
- [Mergify](https://mergify.com) — GitHub 的工作流自动化与合并队列；公共 GitHub 仓库免费。
- [Nx Cloud](https://nx.dev/ci) — 在 CI 上加速 monorepo：远程缓存、跨机器分发任务、自动拆分 e2e 测试等；免费方案最多 30 名贡献者，含 15 万 credits。
- [RunMyJob](https://runmyjob.io) — 用实时伸缩的 Spike 实例更聪明地跑 GitHub Actions 与 GitLab CI；免费档：400 vCPU-分钟、800 GB-分钟、10 个并发任务，高性能 runner（每任务 12 vCPU、32GB RAM）。
- [Shipfox](https://www.shipfox.io/) — 让 GitHub Actions 快 2 倍；每月 3,000 免费构建分钟。
- [Spacelift](https://spacelift.io/) — IaC 管理平台。免费方案：IaC 协作、Terraform 模块注册表、ChatOps 集成、Open Policy Agent 持续资源合规、SAML 2.0 SSO、公共 worker 池——每月最多 200 分钟。
- [Squash Labs](https://www.squash.io/) — 为每个分支创建虚拟机，从唯一 URL 访问你的应用；公共与私有仓库不限；VM 最大 2GB。
- [Terramate](https://terramate.io/) — Terraform、OpenTofu、Terragrunt 等 IaC 工具的编排与管理平台；最多 2 名用户免费、含全部功能。
- [Terrateam](https://terrateam.io) — GitOps 优先的 Terraform 自动化：拉取请求驱动的工作流、经自托管 runner 实现项目隔离、分层运行保证有序执行；最多 3 名用户免费。
- [Trigger.dev](https://trigger.dev) — 开源后台任务与 AI Agent 平台：持久任务、无超时、实时。免费方案：每月 $5 计算额度、20 个并发运行、任务不限、5 名团队成员、10 个调度、1 天日志保留。


## 测试（Testing）

- [Appetize](https://appetize.io) — 直接在浏览器里用云端 Android 手机/平板模拟器与 iPhone/iPad 模拟器测试应用；免费档含 2 个并发会话、每月 30 分钟用量；应用体积不限。
- [Argos](https://argos-ci.com) — 开源可视化测试：项目不限量、每月 5,000 张截图；开源项目免费。
- [Bencher](https://bencher.dev/) — 持续基准测试工具套件，捕捉 CI 性能回退；所有公共项目免费。
- [BugBug](https://bugbug.io/) — 轻量 Web 应用测试自动化：易学、无需编码；在自己电脑上免费无限量运行测试；云监控与 CI/CD 集成需另付费。
- [checkbot.io](https://www.checkbot.io/) — 浏览器扩展，检测网站是否遵循 50+ 项 SEO、速度与安全最佳实践；小型网站免费档。
- [Checkly](https://checklyhq.com) — 面向现代 DevOps 的代码优先合成监控：以远低于传统厂商的价格监控 API 与应用；基于 Monitoring as Code 工作流与 Playwright；开发者免费档慷慨。
- [CORS-Tester](https://cors-error.dev/cors-tester/) — 面向开发与 API 测试的免费工具：检查某个 API 对指定域名是否启用 CORS、找出缺口并给出可执行建议。
- [cypress.io](https://www.cypress.io/) — 快速、简单、可靠的浏览器内测试；Cypress Test Runner 永久免费开源、无限制；Cypress Dashboard 对开源项目免费（最多 5 用户）。
- [everystep-automation.com](https://www.everystep-automation.com/) — 录制并回放浏览器中的每一步操作并生成脚本；免费版功能较少。
- [gridlastic.com](https://www.gridlastic.com/) — Selenium Grid 测试：免费方案最多 4 个并发 selenium 节点 / 10 次 grid 启动 / 每月 4,000 测试分钟。
- [katalon.com](https://katalon.com) — 覆盖各测试成熟度团队的测试平台：Katalon Studio、TestOps（含免费 Visual Testing）、TestCloud、Katalon Recorder。
- [Keploy](https://keploy.io/) — 开发者功能测试工具包：录制 API 调用即可生成 API 端到端测试（KTests）与 mock/stub（KMocks）；开源项目免费。
- [Lastest](https://lastest.cloud) — 快速上线而不破坏东西：AI 支持的可信可视化验证与测试。永久免费方案：1 个项目、每月 500 runner 分钟、1 个并发运行，无需信用卡。
- [loadmill.com](https://www.loadmill.com/) — 通过分析网络流量自动创建 API 与负载测试；每月免费模拟最多 50 个并发用户、最长 60 分钟。
- [lost-pixel.com](https://lost-pixel.com) — 面向 Storybook、Ladle、Histoire 故事与 Web 应用的整体视觉回归测试；团队成员不限，开源完全免费，每月 7,000 张快照。
- [pagegym.com](https://pagegym.com) — 加载行为与页面速度分析与优化工具；免费方案每天 10 次测试、每周 5 个实验、每月最多摄入 15GB 数据。
- [percy.io](https://percy.io) — 为任何 Web 应用、静态站点、样式指南或组件库添加可视化测试；团队成员不限、含演示应用、项目不限，每月 5,000 张快照。
- [qase.io](https://qase.io) — 面向开发与 QA 团队的测试管理系统：管理用例、编排测试运行、执行测试、跟踪缺陷、衡量影响。免费档含全部核心功能：500MB 附件空间、最多 3 名用户。
- [Repeato](https://repeato.app/) — 基于计算机视觉与 AI 的无代码移动应用测试自动化：适用于原生、Flutter、react-native、web、ionic 等框架。免费方案限 iOS 与 Android 各 10 个测试，但含付费方案的多数功能（含不限次数的测试运行）。
- [Requestly](https://requestly.com/) — 开源 Chrome 扩展：拦截、重定向、mock HTTP 请求；含 [Debugger](https://requestly.com/products/web-debugger/)、[Mock Server](https://requestly.com/products/mock-server/)、[API Client](https://requestly.com/products/api-client/)、[Session Recording](https://requestly.com/products/session-book/)；可重定向 URL、改 HTTP 头、mock API、注入自定义 JS、改 GraphQL 请求、生成 Mock API 端点、录制含网络与控制台日志的会话。免费档最多 10 条规则；开源免费。
- [Sample Files](https://mzeeshan.me/tools/sample-files) — 覆盖视频、音频、文档与压缩包格式的免费测试文件合集，适合测试与 QA。
- [seotest.me](https://seotest.me/) — 免费页面内 SEO 测试器：每天 10 次免费网站抓取；附实用的 SEO 学习资源与改进建议（不限技术栈）。
- [Sherlo](https://sherlo.io) — React Native 应用视觉回归测试；免费方案：每月 1,000 张快照、iOS 与 Android 模拟器。
- [snippets.uilicious.com](https://snippets.uilicious.com) — 像 CodePen 但面向跨浏览器测试：UI-licious 让你像写用户故事一样写测试；免费平台 UI-licious Snippets 可在 Chrome 上无限测试（无需注册，单次测试最长 3 分钟）；发现 bug 可复制唯一 URL 精确展示复现路径。
- [SSR (Server-side Rendering) Checker](https://www.crawlably.com/ssr-checker/) — 对比服务端渲染版本与常规版本来检查任意 URL 的 SSR。
- [testingbot.com](https://testingbot.com/) — Selenium 浏览器与设备测试；[开源免费](https://testingbot.com/open-source)。
- [Testspace.com](https://testspace.com/) — 发布自动化测试结果的仪表盘 + 用 GitHub 把手工测试实现为代码的框架；[开源免费](https://github.com/marketplace/testspace-com)，每月 450 条结果。
- [tesults.com](https://www.tesults.com) — 测试结果报告与用例管理，集成主流测试框架；开源开发者、个人、教育者与起步小团队可在基础免费项目之外申请折扣与免费名额。
- [UseWebhook.com](https://usewebhook.com) — 在浏览器里捕获与检查 webhook：转发到 localhost 或从历史重放；免费。
- [Vaadin](https://vaadin.com) — 用 Java 或 TypeScript 构建可扩展 UI；配套工具、组件与设计系统助你更快迭代。项目不限量、5 年免费维护。
