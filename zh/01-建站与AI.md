## 生成式 AI（Generative AI）

- [Arize AX](https://arize.com) — AI 工程平台，帮 AI 工程师 / 产品经理用内置 Alyx agent 评估、观测 AI 应用与 Agent。免费版含每月 2.5 万 spans 与 1GB 摄入量。
- [Audio Enhancer](https://voice-clone.org/tools/audio-enhancer) — AI 音频增强 SaaS，去除噪音与回声同时保留人声清晰度。完全免费：无限次一键增强、无需登录，支持 MP3/WAV/FLAC。
- [Braintrust](https://www.braintrustdata.com/) — Gen AI 的评测（Evals）、提示词工作台与数据管理。免费方案每周最多 1,000 行私有评测。
- [Clair](https://askclair.ai/) — 临床 AI 参考。学生可免费使用专业工具套件（Open Search、Clinical Summary、Med Review、Drug Interactions、ICD-10 Codes、Stewardship），另有专业套件免费试用。
- [Comet Opik](https://www.comet.com/site/products/opik/) — 跨开发与生产全生命周期评测、测试与交付 LLM 应用。[#opensource](https://github.com/comet-ml/opik/)
- [Future AGI](https://futureagi.com) — 开源平台，评测、观测、改进 LLM 与 AI Agent 应用，含追踪、评测、模拟与护栏。免费档：50GB 存储、2K 评测额度、每月 10 万次 AI 网关请求、100 万 token 文本 agent 模拟 + 60 分钟语音模拟，项目/席位不限，BYOK LLM-as-judge 平台零费用。[#opensource](https://github.com/future-agi/future-agi)
- [Gonka Broker](https://gonkabroker.com/) — 兼容 OpenAI 的 API，经去中心化 Gonka.ai GPU 网络提供开源模型。每月 100 万+ 免费 token，易集成。
- [Keywords AI](https://keywordsai.co) — LLM 监控平台，号称两行代码统一调用 200+ LLM。每月 1 万次免费请求，平台功能 $0。
- [Langfuse](https://langfuse.com/) — 开源 LLM 工程平台，帮团队协作调试、分析、迭代 LLM 应用。免费永久方案：每月 5 万条观测 + 全部平台功能。[#opensource](https://github.com/langfuse/langfuse)
- [LangWatch](https://langwatch.ai) — LLMOps 平台，度量、监控、优化 LLM 应用（可靠性、成本、性能），含 DSPy 组件。免费方案含全部平台功能、每月 1k traces、1 个 DSPy 优化工作流。[#opensource](https://github.com/langwatch/langwatch)
- [Latitude](https://latitude.so) — 开源（MIT）LLM 可观测与评测平台，生产环境 trace、监控、评测 AI agents。免费 Starter：每月 20K credits、30 天数据保留、席位不限。[#opensource](https://github.com/latitude-dev/latitude-llm)
- [Lumenfall.ai](https://lumenfall.ai/) — AI 媒体网关，用兼容 OpenAI 的 API 统一访问主流图像生成模型。平台免费、零加价、无订阅费；多数模型按供应商原价计费，但 FLUX.1 [schnell] FP8 对注册用户永久免费且不限量；内置故障转移与供应商容灾。
- [Maxim](https://www.getmaxim.ai) — LLM 评测与可观测平台，含 agent 模拟与提示词工作台。免费档每月 1 万条日志，BYOK 可用工作台、模拟与评测。
- [Mediaworkbench.ai](https://mediaworkbench.ai) — 为 Azure OpenAI、DeepSeek、Google Gemini 提供 10 万免费词，可用于代码生成、深度研究、图像创作。
- [OpenRouter](https://openrouter.ai/models?q=free) — 提供多种免费 AI 模型（含 DeepSeek R1/V3、Llama、Moonshot AI），适合各类开发需求；免费模型有速率限制。另提供 Claude、OpenAI、Grok、Gemini、Nova 等付费模型。
- [Pollinations.AI](https://pollinations.ai/) — 易用的免费 AI 图像生成，有免费 API；无需注册或 API key，可多种方式集成进网站或工作流。[#opensource](https://github.com/pollinations/pollinations)
- [Portkey](https://portkey.ai/) — Gen AI 应用控制台：可观测套件 + AI 网关。每月免费发送与记录最多 1 万次请求。
- [ReportGPT](https://ReportGPT.app) — AI 写作助手。自带 API key 即可免费使用整个平台。
- [telemetry.dev](https://telemetry.dev) — 基于 OpenTelemetry 的 AI/LLM 可观测：追踪模型调用与工具步骤的 token、成本、延迟与错误；任何语言经 HTTP 发 OTLP，或用 TypeScript SDK。免费方案：每月 1 万 spans、7 天保留、1 项目、2 席位，无需信用卡。
- [Transcript LOL](https://transcript.lol/) — 用 AI 把音视频转文字，再用 LLM 生成摘要等洞察。免费档每天 2 次转写；可上传文件、录语音，或用 YouTube、Instagram 等链接；免费版还支持 WhatsApp、Telegram 及从 Google Drive、Dropbox、Box、OneDrive 直接导入。无需 API key，注册即用；有移动端 / 桌面端 / Chromebook 应用。
- [Zenable](https://zenable.io) — 用 Policy as Code 构建护栏，自动修复 Cursor、Windsurf、Copilot 等工具的输出以符合企业质量与合规标准。免费档：MCP 服务器每天 100 次工具调用，GitHub App 每天 25 次自动 PR 审查。


## Web 托管（Web Hosting）

- [Alwaysdata](https://www.alwaysdata.com/) — 1GB 免费虚拟主机，支持 MySQL、PostgreSQL、RabbitMQ、.NET、Deno、Elixir、Go、Java、Lua、Node.js、PHP、Python、Ruby、Rust；可自定义 Web 服务器，经 FTP、WebDAV、SSH 访问；含邮箱、邮件列表与应用安装器。免费方案不支持自定义域名。
- [Awardspace.com](https://www.awardspace.com) — 免费虚拟主机 + 免费短域名，含 PHP、MySQL、应用安装器、邮件发送，无广告。
- [boomurl](https://boomurl.com) — 无需账号，把静态站点（HTML/Markdown/图片/PDF 或整个文件夹）发布为即时 HTTPS URL；免费档显示小横幅；支持自定义域名。
- [Bubble](https://bubble.io/) — 可视化编程，不写代码构建 Web 与移动应用；免费版带 Bubble 品牌标识。
- [dAppling Network](https://www.dappling.network/) — 面向 Web3 前端的去中心化 Web 托管，侧重提升可用性、安全性，为用户提供额外访问点。
- [DigitalOcean](https://www.digitalocean.com/pricing) — 在 App Platform Starter 档免费构建并部署 3 个静态站点。
- [FreeFlarum](https://freeflarum.com/) — 社区驱动的免费 Flarum 托管，最多 250 用户（捐赠可去页脚水印）。
- [Harvis.dev](https://harvis.dev) — CLI（`npx harvis`）一键静态托管，无需配置文件与构建步骤；含免费子域名、免费表单收集、GitHub Actions 集成、CloudFlare CDN、免费 SSL。
- [Koyeb](https://www.koyeb.com/) — Serverless 平台。免费 Hobby 方案：每月 550 小时免费算力（512MB RAM）、1 个免费 PostgreSQL、自定义域名 SSL。
- [MDB GO](https://mdbgo.com/) — 免费托管 1 个项目：Container TTL 两周、每项目 500MB RAM、SFTP、1GB 磁盘。
- [Mirin](https://mirin.com) — 面向开发者用 React/Vue/Svelte 做组件站点的平台：可视化编辑、表单、分析、全球 CDN 托管。免费档含 1 个站点，页面与提交不限量。
- [Neocities](https://neocities.org) — 静态托管：1GB 免费存储、200GB 带宽。
- [Netlify](https://www.netlify.com/) — 免费构建、部署、托管静态站点/应用，每月 300 credits（约合 30GB 带宽）。
- [PandaStack](https://www.pandastack.io/) — 开发者生态系统，多种 Web 托管形态（静态、容器化、WordPress 等托管应用，几下点击完成）。免费 1 个静态或容器化托管 + 1 个免费数据库，100GB 带宽、每月 300 构建分钟。
- [pantheon.io](https://pantheon.io/) — Drupal 与 WordPress 托管：自动化 DevOps、可扩展基础设施。开发者与代理免费；不支持自定义域名。
- [Qoddi](https://qoddi.com) — 类 Heroku 的 PaaS，以开发者为中心、功能全面。静态资源、staging 与开发者应用有免费档。
- [readthedocs.org](https://readthedocs.org/) — 免费文档托管，含版本管理、PDF 生成等。
- [render.com](https://render.com) — 统一云平台构建与运行应用/站点：免费 SSL、全球 CDN、私有网络、Git 自动部署；Web 服务、数据库、静态网页均有完全免费方案。
- [Revdoku](https://revdoku.com/) — 直接从 ChatGPT、Claude、Codex 等 AI 代理把文件、报告、定制微站发布为公开或密码保护的网站。免费档：2GB 存储、2 个在线站点/应用、1 个数据库（25MB）、3 个 AI 连接、每桶 1k 文件（单文件上限 100MB）、基础分析。
- [ShipStatic](https://shipstatic.com) — AI 代理可自行驱动的静态托管：`npx @shipstatic/ship ./dist` 即上线，无需安装/注册/仓库/构建；另有 MCP、SDK、API。免费账号站点永久保留，自动 HTTPS、全球边缘分发、不限量带宽；自定义域名收费。
- [SourceForge](https://sourceforge.net/) — 免费查找、创建与发布开源软件。
- [surge.sh](https://surge.sh/) — 面向前端开发者的静态网页发布。站点不限量，支持自定义域名。
- [tilda.cc](https://tilda.cc/) — 免费 1 个站点、50 页、50MB 存储；仅可用 170+ 预置模块中的主要模块；无字体、无 favicon、无自定义域名。
- [Vercel](https://vercel.com/) — 构建、部署、托管 Web 应用：免费 SSL、全球 CDN，每次 `git push` 生成独立 Preview URL。适合 Next.js 与其他静态站点生成器。
- [Versoly](https://versoly.com/) — 面向 SaaS 的建站工具：网站不限量、70+ 模块、5 个模板、自定义 CSS、favicon、SEO、表单。不支持自定义域名。
- [Stormkit](https://www.stormkit.io) — 可自托管的 Vercel 替代品，构建、托管、部署现代前端/JavaScript 应用。免费方案：1 个应用、50GB 带宽、自定义域名不限、免费 SSL。


## DNS

- [1.1.1.1](https://developers.cloudflare.com/1.1.1.1/) — Cloudflare 提供的免费公共 DNS 解析器，快速且安全（加密 DNS 查询）。可绕过运营商 DNS 封锁、防止查询被窥探，也[可拦截成人及恶意内容](https://developers.cloudflare.com/1.1.1.1/1.1.1.1-for-families)；支持[通过 API 使用](https://developers.cloudflare.com/1.1.1.1/encrypted-dns/dns-over-https/make-api-requests)。注意：仅 DNS 解析器，非 DNS 托管。
- [1984.is](https://www.1984.is/product/freedns/) — 免费 DNS 服务，含 API 及多种其他免费 DNS 功能。
- [cloudns.net](https://www.cloudns.net/) — 免费 DNS 托管，最多 1 个域名、50 条记录。
- [deSEC](https://desec.io) — 免费 DNS 托管，支持 API，以安全为设计目标；基于开源软件，由 [SSE](https://www.securesystems.de/) 支持。
- [dns.he.net](https://dns.he.net/) — 免费 DNS 托管，支持动态 DNS。
- [dnspod.com](https://www.dnspod.com/) — 免费 DNS 托管（腾讯云旗下）。
- [duckdns.org](https://www.duckdns.org/) — 免费动态 DNS，免费档最多 5 个域名，附多种配置指南。
- [Dynv6.com](https://dynv6.com/) — 免费 DDNS 服务，支持 [API](https://dynv6.com/docs/apis)，可管理多种记录类型（CNAME、MX、SPF、SRV、TXT 等）。
- [freedns.afraid.org](https://freedns.afraid.org/) — 免费 DNS 托管；还基于用户贡献的众多公共域名提供免费子域名，注册后从 "Subdomains" 菜单获取。
- [Glauca](https://docs.glauca.digital/hexdns/) — 免费 DNS 托管，最多 3 个域名，支持 DNSSEC。
- [Hetzner](https://www.hetzner.com/dns-console) — Hetzner 的免费 DNS 托管，支持 API。
- [huaweicloud.com](https://www.huaweicloud.com/intl/en-us/product/dns.html) — 华为云免费 DNS 托管。
- [LocalCert](https://localcert.net) — 免费 `.localcert.net` 子域名，与公共 CA 兼容，可用于私有网络内。
- [luadns.com](https://www.luadns.com/) — 免费 DNS 托管：3 个域名，合理限制下开放全部功能。
- [namecheap.com](https://www.namecheap.com/domains/freedns/) — 免费 DNS，域名数量不限。
- [nextdns.io](https://nextdns.io) — 基于 DNS 的防火墙，每月 30 万次免费查询。
- [noip.at](https://noip.at/) — 免费 DDNS：无需注册、无追踪、无日志、无广告，域名不限。
- [noip](https://www.noip.com/) — 动态 DNS，免费最多 3 个主机名，需每 30 天确认一次。
- [sslip.io](https://sslip.io/) — 免费 DNS：用内嵌 IP 的主机名查询时，返回该 IP。
- [zilore.com](https://zilore.com/en/dns) — 免费 DNS 托管，5 个域名。
- [zoneedit.com](https://www.zoneedit.com/free-dns/) — 免费 DNS 托管，支持动态 DNS。
- [Zonomi](https://zonomi.com/) — 免费 DNS 托管，即时生效。免费方案：1 个 DNS zone（域名）最多 10 条记录。

## CDN 与防护（CDN and Protection）

- [bootstrapcdn.com](https://www.bootstrapcdn.com/) — bootstrap、bootswatch 与 fontawesome.io 的 CDN
- [CacheFly](https://portal.cachefly.com/signup/free2023) — 每月最多 5TB 免费 CDN 流量、19 个核心 PoP、1 个域名与通用 SSL
- [cdnjs.com](https://cdnjs.com/) — 简单、快速、可靠的内容分发。cdnjs 是免费开源 CDN 服务，由 Cloudflare 驱动，全球 11%+ 网站在用
- [developers.google.com](https://developers.google.com/speed/libraries/) — Google Hosted Libraries：最热门开源 JavaScript 库的内容分发网络
- [Gcore](https://gcorelabs.com/) — 全球内容分发网络，每月 1TB 与 100 万次请求免费，另含免费 DNS 托管
- [jsdelivr.com](https://www.jsdelivr.com/) — 免费、快速、可靠的开源 CDN，支持 npm、GitHub、WordPress、Deno 等
- [Microsoft Ajax](https://learn.microsoft.com/en-us/aspnet/ajax/cdn/overview) — Microsoft Ajax CDN 托管 jQuery 等热门第三方 JavaScript 库，轻松加到 Web 应用
- [Namecheap Supersonic](https://www.namecheap.com/supersonic-cdn/#free-plan) — 免费 DDoS 防护
- [ovh.ie](https://www.ovh.ie/ssl-gateway/) — 免费 DDoS 防护与 SSL 证书
- [PromoProxy](https://promoproxy.net/) — 免费云安全 Web 网关。免费版最多 5 用户与每天 1GB
- [raw.githack.com](https://raw.githack.com/) — **rawgit.com** 的现代替代品，用 Cloudflare 托管文件
- [Skypack](https://www.skypack.dev/) — 100% 原生 ES Module 的 JavaScript CDN。每域名每月 100 万次请求免费
- [statically.io](https://statically.io/) — Git 仓库（GitHub、GitLab、Bitbucket）、WordPress 相关资源与图片的 CDN
- [Stellate](https://stellate.co/) — 极速可靠的 GraphQL API CDN，两个服务免费
- [toranproxy.com](https://toranproxy.com/) — Packagist 与 GitHub 的代理，CD 永不失败。个人使用免费：1 名开发者，无支持
- [UNPKG](https://unpkg.com/) — npm 上一切的 CDN
- [weserv](https://images.weserv.nl/) — 图片缓存与缩放服务：全球缓存下即时操作图片
