## ⚠️ 使用提醒（字体授权）

中文字体侵权是国内自媒体/开发者的高发坑：**"免费下载 ≠ 免费商用"**。使用任何字体前请核对授权原文——开源中文字体（思源黑体/宋体、霞鹜文楷、得意黑等）多为 SIL OFL 1.1 可放心商用；厂商"免费"字体（MiSans、HarmonyOS Sans、OPPO Sans 等）通常禁止改动字体本体与单独转售；方正免费四款**仅免商业发布，嵌入 App / Web Font / 商标注册不在免费范围**。详见 [08-中文字体免费商用清单](zh/08-中文字体免费商用清单.md)。
